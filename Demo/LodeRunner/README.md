# Lode Runner assets

The demo's Lode Runner view plays level 1 of *Lode Runner* (Doug Smith / Broderbund, 1983, Apple II) using graphics,
sounds and the level map extracted from the original disk image by the Retro2Arcade project.

Those files are copyrighted by their publisher and are used for private study only, so they are **not** in this
repository. This folder is ignored by git apart from this file. To install them, run from the repository root:

```sh
scripts/import-lode-runner-assets.sh /path/to/Retro2Arcade
```

and rebuild the demo. Without them, the Lode Runner view explains how to get them.
